## 🌐 About this repository

This is the source code of my portfolio: **[tiagoaderbal.vercel.app](https://tiagoaderbal.vercel.app)**.
It is a regular portfolio that got slightly out of control.

| | Feature | What it does |
|:-:|---|---|
| 🤖 | **A.T.L.A.S.** | An AI assistant that answers questions about my career, stack and projects. It runs on a Vercel serverless function with the Gemini API, a model fallback chain and a prompt-injection guard. |
| 🧟 | **Invaded "About me" page** | The career section gets corrupted, letter by letter, until ATLAS takes its place. |
| 🌗 | **Dark side / Light side** | Theme toggle starring Darth Vader and Master Yoda. |
| 🧰 | **Utility dock** | Coffee level, build status, known bugs, last deploy, loaded tools and random dev jokes. |
| 📝 | **Blog** | Articles about software engineering, AI and cybersecurity, rendered from Markdown. |
